# FTM (Follow the Money)

An interactive research site on the world's 100 largest fortunes (Forbes, March 2026 snapshot). The site is one standalone HTML file. The dataset is `window.RESEARCH` inside it.

- For the research task on the top 50, follow `RESEARCH_BRIEF.md`.
- Research output format: `schema/person.schema.json`.
- Use plain Node scripts with no dependencies by default. Justify any dependency you add.
- Never change a person's editorial `status` (red, orange, green). Propose changes in `REVIEW.md` instead.
